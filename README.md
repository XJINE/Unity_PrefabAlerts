# Unity_PrefabAlerts

<img src="https://github.com/XJINE/Unity_PrefabAlerts/blob/main/Screenshot.png" width="100%" height="auto" />

Highlights overridden Prefabs in the Hierarchy and Inspector.

Should support Unity 6.3(6000.3.x) and later.

## Importing

You can use Package Manager or import it directly.

```
https://github.com/XJINE/Unity_PrefabAlerts.git?path=Assets/Packages/PrefabAlerts
```

## How to Use

You can change the highlight color from ``Custom > Prefab Alerts``.
